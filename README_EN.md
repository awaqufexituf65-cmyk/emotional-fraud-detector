# Emotional Fraud Detector 💔🔍

An open-source Claude Code skill for detecting romance scams, pig-butchering fraud, and emotional manipulation in chat conversations. Provides psychological support and safety guidance.

---

## What is this?

Emotional Fraud Detector analyzes chat messages to identify:

- 🔍 **Scam Pattern Matching** — 7 known romance scam types (pig-butchering, fake military/doctor, sextortion, etc.)
- 🚩 **Red Flag Scoring** — 4-tier weighted system (P0 Critical → P3 Low)
- 🧠 **Manipulation Tactic Detection** — 8 psychological manipulation tactics
- 📋 **4-Level Verdict** — HIGH RISK / ELEVATED CONCERN / LOW RISK / INSUFFICIENT DATA
- 🛡️ **Tiered Response Guidance** — Concrete action steps by risk level
- 💚 **Psychological Support** — Auto-triggered after high-risk findings
