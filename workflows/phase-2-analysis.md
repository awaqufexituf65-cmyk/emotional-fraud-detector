# Phase 2 详细流程: 深度分析

## 分析准备

在开始分析之前，确保以下材料已就绪：
- [ ] Phase 1 事实基础文档
- [ ] 用户提供的聊天记录（原文）
- [ ] 数据充分性评估结果

---

## 步骤 1: 诈骗模式匹配

### 操作方法
1. 阅读 `references/fraud-patterns.md`
2. 对 7 种诈骗类型逐项对照：
   - 杀猪盘
   - 冒充军人/医生
   - 裸聊敲诈
   - 投资导师型
   - 跨国包裹诈骗
   - 紧急事件型
   - 往返型/幽灵型
3. 每种类型评估：完全匹配 / 部分匹配 / 未匹配

### 匹配标准
- **完全匹配**: ≥3 个核心特征 + 对话模式高度吻合
- **部分匹配**: 1-2 个核心特征 + 部分吻合
- **未匹配**: 不满足任何核心特征

### 输出格式
```
诈骗模式匹配结果：
- 杀猪盘: [完全匹配/部分匹配/未匹配] — [匹配的特征列表]
- 冒充军人/医生: [匹配/未匹配]
- ...
最佳匹配类型: [最吻合的诈骗类型]
```

### 注意事项
- 用户可能同时匹配多种诈骗类型的特征 → 取最吻合的
- 如果所有类型都不匹配但红旗评分高 → 可能为新型诈骗
- 不要为了"匹配"而强行套用

## 步骤 2: 操控手法识别

### 操作方法
1. 阅读 `references/manipulation-tactics.md`
2. 对 8 种操控手法逐项检查：
   - 爱情轰炸
   - 画大饼
   - 孤立
   - 情感绑架
   - 冷热交替
   - 煤气灯效应
   - 制造紧迫感
   - 创伤纽带
3. 每种手法标注：是否出现 / 出现频次 / 严重程度

### 输出格式
```
操控手法识别结果：
- 爱情轰炸: [是/否] — 出现 [N] 次 — [严重/中度/轻度]
  证据: "[用户聊天记录中的原文]"
- 画大饼: [是/否] — 出现 [N] 次 — [严重/中度/轻度]
  证据: "..."
...
操控手法总计: [N] 种，其中严重 [N] 种
```

### 严重程度判定
- **严重**: 该手法频繁出现 + 与金钱/隐私要求结合
- **中度**: 该手法偶发出现，不算频繁但值得注意
- **轻度**: 偶发 1-2 次，不构成明显模式

## 步骤 3: 红旗评分

### 操作方法
1. 阅读 `references/red-flags-checklist.md`
2. 逐项检查 P0-P3 红旗，打勾并记录证据
3. 计算综合分数

### 评分计算

```
P0 命中: [N] 项 × 25 = [分数]
P1 命中: [N] 项 × 10 = [分数]
P2 命中: [N] 项 × 4 = [分数]
P3 命中: [N] 项（不纳入主分，仅辅助）

基础分: [总分]
数据调整因子: × [0.5 / 0.8 / 1.0]
紧急因子(如有转账): × [1.0 / 1.5]
最终综合分: [分数]
```

### 输出格式
```
红旗评分结果：
P0(致命): [N] 项 — [具体项目编号和证据]
P1(高危): [N] 项 — [具体项目编号和证据]
P2(中危): [N] 项 — [具体项目编号和证据]
P3(低危): [N] 项

综合分数: [分数] (P0×25 + P1×10 + P2×4)
数据调整: ×0.8 (对方消息 15 条)
最终分数: [分数]

对应判定区间: [🔴≥25 / 🟠10-24 / 🟡4-9 / 🟢<4]
```

## 步骤 4: 行为时间线

### 操作方法
按时间顺序排列关键事件，标注：
- 关系发展节点（什么时候开始叫宝贝？）
- 红旗首次出现的时间
- 操控手法的拐点（什么时候开始变的？）
- 金钱话题首次出现的位置

### 输出格式
```
时间线:
[Day 1-3]  匹配 + 基础自我介绍
[Day 4]    称呼变为"宝贝" ★ (爱情轰炸出现)
[Day 7]    对方首次提到"未来计划" — "我们以后..." ★ (画大饼)
[Day 14]   对方提到"副业投资" ★★ (金钱铺垫开始)
[Day 21]   第一次建议你投资 ★★★ (P0触发)
...
```

### 关键分析点
- 从认识到第一次出现红旗的时间间隔（越短越可疑）
- 感情升温速度（<1周确立"恋爱关系"→ 可疑）
- 金钱话题是在感情热度最高的时候提出的吗？（典型杀猪盘模式）

## 步骤 5: 反事实分析

### 目的
防止确认偏差——不因为用户已经怀疑就默认对方有问题。

### 操作方法
对每个关键红旗，问自己：
> "如果这是一个正常、真诚的关系，这个行为有没有合理的解释？"

### 输出格式
```
反事实分析：
红旗: 对方不愿意视频通话
 → 正常解释A: 对方确实工作忙，或者对视频有社恐
 → 正常解释B: 对方用的是老人机/公司限制
 → 合理性评估: 持续2个月、20+次推托 → 正常解释极其牵强
 → 结论: 红旗维持，且加权

红旗: 对方建议投资
 → 正常解释A: 对方是金融从业者，分享专业知识
 → 正常解释B: 对方真的相信这个投资机会好
 → 合理性评估: 平台不在主流应用商店 + "内部消息" → 正常解释不可信
 → 结论: 红旗维持，且加权

红旗: 快速表白("3天就叫宝贝")
 → 正常解释A: 对方表达感情比较直接
 → 正常解释B: 文化差异/性格使然
 → 合理性评估: 结合其他红旗看，可能为爱情轰炸
 → 结论: 无其他红旗时此行为可降级，有多项红旗时维持
```

### 反事实规则
- 如果某个红旗能找到"一个合理的正常解释"，且该解释与其他已知事实不矛盾 → 降低该红旗权重
- 如果正常解释非常牵强，或与已确认的事实矛盾 → 该红旗加权
- 如果所有红旗都有合理的正常解释 → 整体判定应下调
