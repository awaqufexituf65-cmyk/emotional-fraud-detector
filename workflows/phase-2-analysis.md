# Phase 2 详细流程: 逐条对话深度分析 ★

## 分析前准备

确保以下材料已就绪：
- [ ] Phase 1A 使用者画像（年龄/情感状态/脆弱性）
- [ ] Phase 1B 关系背景（认识渠道/平台/金钱概况）
- [ ] 聊天记录原文（WeFlow 导出 / 手动粘贴 / 用户描述）

**推荐阅读顺序**:
1. 先通读 `references/message-analysis.md`（7维分析框架）
2. 需要时查阅 `references/fraud-patterns.md`（诈骗模式参考）
3. 需要时查阅 `references/manipulation-tactics.md`（操控手法参考）
4. 需要时查阅 `references/red-flags-checklist.md`（红旗评分参考）

---

## 步骤 1: 通读聊天记录 + 时间线分段

### 先整体通读
- 从头到尾通读一遍全部聊天记录
- 感受整体节奏——什么时候感情升温？什么时候开始变味？
- 在心里标注第一次出现可疑信号的位置

### 按时间/阶段分组

根据关系发展节奏，将聊天记录分为若干段：

| 分段方式 | 适用条件 |
|----------|---------|
| 按**周**分组 | 聊天时间跨度较长（>1个月），每周对话量较大 |
| 按**关系转折点**分组 | 有明显的关系阶段变化（第一次表白/第一次提钱/第一次拒绝视频等） |
| 按**话题**分组 | 对话有明显的主题切换（在哪个话题之后开始谈钱的） |

**每段选 3-5 条最有代表性的对方消息进行逐条分析**。

选择标准：
- 优先选关系转折点的消息
- 优先选涉及感情/金钱/身份/未来的消息
- 跳过纯寒暄（早安/晚安/吃了吗/今天天气）——除非频率异常高

## 步骤 2: 逐条七维分析

### 2.1 分析每条选中的消息

使用 `references/message-analysis.md` 中的 7 维框架：

**维度 1: 字面含义**
- 把对方原话翻译成最直白的表述
- 不添加解读，只描述字面说了什么

**维度 2: 潜在意图**
判断对方发这条消息的真正目的，从以下类别中选择：
- 建立信任 / 测试服从 / 收集信息 / 制造依赖
- 推进关系 / 铺垫金钱 / 收割施压 / 维持控制
- 日常分享（正常聊天）

**维度 3: 操控手法**
对照 `references/manipulation-tactics.md` 的 8 种手法：
- 爱情轰炸 / 画大饼 / 孤立 / 情感绑架
- 冷热交替 / 煤气灯效应 / 制造紧迫感 / 创伤纽带
- **无**（正常消息）

**维度 4: 红旗等级**
对照 `references/red-flags-checklist.md` 的 4 级：
- 🔴 P0: 致命（要钱/要验证码/诱导下载不明App）
- 🟠 P1: 高危（身份矛盾/快速表白/拒绝视频/推荐投资）
- 🟡 P2: 中危（信息含糊/过度赞美/打探财务/回避某些话题）
- ⚪ P3: 低危（语法可疑/头像完美/不分享日常）
- **无**

**维度 5: 情绪策略**
判断对方使用的情感基调：
- 温暖甜蜜 / 紧迫焦虑 / 内疚亏欠 / 恐惧威胁
- 炫耀展示 / 脆弱求助 / 理性专业 / 冷漠疏远
- 中性

**维度 6: 关系阶段**
判断处于哪个阶段：
- 初步接触 / 感情升温 / 信任构建
- 金钱铺垫 / 收割 / 善后维持 / 失联
- 正常关系（不适用诈骗分类）

**维度 7: 应对建议**
- 接受: 正常回应
- 观察: 记下来，继续观察后续
- 验证: 关键信息需要验证
- 边界: 礼貌但坚定地拒绝
- 停止: 触发明确红旗，停止互动
- 报警: 涉及明确诈骗行为

### 2.2 输出每条消息的分析

```markdown
### 📩 第 N 段 — [时间/阶段标签]

**对方**: > "[原文]"

| 维度 | 分析 |
|------|------|
| 💬 字面含义 | ... |
| 🎯 潜在意图 | ... |
| 🧠 操控手法 | ... 或 **无** |
| 🚩 红旗等级 | 🔴P0 / 🟠P1 / 🟡P2 / ⚪P3 / **无** |
| 🎭 情绪策略 | ... |
| 📍 关系阶段 | ... |
| 💡 当时该怎么回 | ... |
```

### 2.3 重点标注

对于以下类型的消息，额外标注：

- 🔥 **关键转折点** — 此消息之后，关系性质发生了实质性变化
- ⚠️ **P0 红旗** — 应立即停止互动
- ❤️‍🩹 **情感操控** — 对方使用情绪而非逻辑进行操控

## 步骤 3: 整体模式总结

完成所有逐条分析后，汇总输出：

```markdown
## 📊 整体模式总结

### 关系发展曲线
[简要描述从认识到现在的整体发展轨迹]

### 红旗时间线
| 时间 | 触发红旗 |
|------|---------|
| 第 1 周 | 无 |
| 第 2 周 | 🟡 P2: 快速表白（认识3天叫宝贝） |
| 第 3 周 | 🟡 P2: 投资铺垫（首次提到副业收益） |
| 第 4 周 | 🔴 P0: 诱导投资 + 🟠 P1: 拒绝视频 |
| ... | ... |

### 操控手法分布
| 手法 | 次数 | 出现阶段 |
|------|------|---------|
| 爱情轰炸 | 3 | 第2、3、5周 |
| 画大饼 | 5 | 第3-8周持续 |
| 情感绑架 | 2 | 第7、8周 |
| ... | ... | ... |

### 关键转折点 🔥
1. **[日期/第N周]**: [发生了什么事 + 为什么是转折点]
2. ...

### 关系阶段演进
[初步接触 → 感情升温(第2周) → 信任构建(第3-4周) → 金钱铺垫(第5周) → 收割(第6-8周) → 失联(第9周)]

### 综合评价
[2-3 句话整体评价：
1. 这段关系最可疑的地方是什么
2. 最有说服力的反证据是什么（如果有）
3. 为 Phase 3 判定提供一个方向性的铺垫]
```
