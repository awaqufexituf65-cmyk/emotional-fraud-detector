## 通用指导原则

1. **具体**: 不要给抽象的建议（"注意安全"），给可操作的步骤（"去 Google 图片搜索搜他的头像"）
2. **排序**: 最重要的行动放在最前面
3. **可验证**: 每个建议应该是用户可以执行的
4. **不施压**: 使用建议语气（"你可以..."），不是命令语气（"你必须..."）
5. **个性化**: 根据 Phase 1A 的使用者画像调整

## 🔴 高风险指导

### 紧急行动（今天就做）

1. **停止金钱往来**
   ```
   立刻停止向对方转账任何金额。
   不要再支付任何"保证金""税费""解冻费"。
   诈骗者会用"再转一笔就能全拿回来"为理由继续骗你——
   不会的。只会越陷越深。
   ```

2. **停止透露信息**
   ```
   不要再给对方发送：
   - 身份证照片
   - 银行卡号和验证码
   - 家庭住址
   - 工作地址
   - 家人信息
   ```

3. **不要对质**
   ```
   不要质问对方"你是不是骗子"。
   对方是训练有素的操控者，他们有准备好的答案。
   对质的结果通常是：对方让你更相信他，然后你继续转账。
   正确的做法是突然停止回复，不给对方任何操作空间。
   ```

### 证据保全（24小时内完成）

4. **截图保存**
   - 所有聊天记录（包括被撤回但你已经看到的内容）
   - 对方的账号信息（微信号/QQ号/手机号）
   - 所有转账记录（银行流水/微信支付记录/支付宝记录）
   - 投资平台的界面截图（你的账户余额、交易记录、客服对话）

## 🟠 中高风险指导

### 立即验证

1. **要求视频通话**
   ```
   "我觉得我们认识有一段时间了，我想跟你视频聊聊天。
   不用很久，10分钟就行，我想看看你。"
   ```
   如果对方推脱 → 这是一个重要的验证结果。记下来。
   如果对方答应 → 准备好在视频中问一些只有真人能回答的问题。

2. **搜索照片**
   - [Google 图片搜索](https://images.google.com) — 上传对方的照片
   - 百度识图 (image.baidu.com) — 同上
   - 如果照片出现在多个地方（不同名字、不同身份）→ 盗图

3. **验证具体信息**
   问一些具体的、可验证的问题：
   - "你说你在[XX公司]上班，公司全称是什么？在哪个区？"
   - "你在哪读的大学？哪一届？什么专业？"
   观察对方回答的自然程度和详细程度。

4. **告诉一位朋友**
   - 把你的疑虑和聊天截图给信任的朋友看
   - 第三方没有情感投入，看得更清楚
   - "你觉得这个人正常吗？"——听听第三方怎么说

### 安全底线

- 不管对方说什么，**不要转账**
- 不要下载对方推荐的不明 App
- 不要发送私密照片或视频
- 不要单独见面（如果决定见面 → 见 communication-guide.md 安全见面指南）

## 🟡 中度疑虑指导

### 收集更多信息

1. **延长观察期**: 再聊 2-4 周，但不做任何重大决定（不表白、不转账、不见面）
2. **注意观察**:
   - 对方是否回避某个话题
   - 对方的信息前后是否一致
   - 对方是否推动关系快速升级
   - 对方的"困难"来得是否太巧
3. **尝试验证**: 同上方的视频通话和照片搜索建议

### 设定边界测试

4. **拒绝一个小请求**
   - 看对方的反应：尊重你的拒绝 vs 生气/冷淡/施压
   - 这是一个试探对方真实性格的好方法

5. **表达一个疑虑**
   - "你上次说的那个事，跟我之前听的不太一样..."
   - 正常反应：解释清楚、不生气
   - 可疑反应：转移话题、生气、说你"不信任我"

## 🟢 低风险指导

### 健康关系建议

1. 保持正常的节奏，不要因为"怕被骗"而过度警惕
2. 如果有机会，线下在公共场所见面（见 communication-guide.md 安全指南）
3. 保持基础的网恋安全意识
4. 享受这段关系——数据分析到此为止

### 基础安全提醒

- 第一次见面在公共场合
- 告知朋友你的行踪
- 在足够了解之前，不涉及大额金钱往来
- 正常的感情不需要金钱投入来证明

## ⚪ 数据不足指导

### 收集建议

1. 需要更多聊天记录：建议至少积累 20-30 条对话后再分析
2. 对话应该涵盖不同话题（日常、工作、兴趣、过去），不只是寒暄
3. 建议持续 2-4 周后再分析，可以看到时间线模式

### 现阶段安全提醒

- 在确认对方身份之前：不转账、不透露敏感信息、不发送私密内容
- 保持观察，留意本技能 Phase 2 中列出的红旗
- 你的直觉已经让你来了这里，继续保持这份警觉

## 个性化调整

根据 Phase 1A 的使用者画像：

| 使用者特征 | 调整方式 |
|-----------|---------|
| 脆弱性高 | 建议更具体 + 更多支持资源 + "这不是你的错" |
| 已有大额金钱损失 | 优先指导资金追回 + 报警步骤排在第一 |
| 中老年 (50+) | 语言更简单 + 鼓励请子女或年轻朋友协助操作 |
| 缺乏社交支持 | 强调可以打热线电话求助 + 鼓励联系至少一个朋友 |
| 冷静理性型 | 给数据 + 给选项 + 少情感引导 |
