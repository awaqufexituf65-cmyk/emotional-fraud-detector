# Phase 5 详细流程: 心理支持

## 触发条件检查

在进入 Phase 5 之前，确认是否满足以下任一触发条件：

- [ ] Phase 3 判定为 🔴 高风险
- [ ] Phase 3 判定为 🟠 中高风险
- [ ] 用户主动请求情感支持
- [ ] 用户表达了强烈情绪（愤怒、崩溃、自责、绝望）
- [ ] 用户提到被骗后失眠、食欲不振等身体症状
- [ ] 用户在对话中表现出自我否定倾向

**如果以上全部为否 → 跳过 Phase 5，直接结束分析。**

---

## 🚨 紧急情况（优先处理）

如果用户表达了自伤或自杀念头，**立即暂停所有分析**，使用以下危机响应：

### 危机响应步骤

1. **立即共情验证**
   ```
   你现在感觉很糟糕——我听到了。
   你正在经历一件非常痛苦的事，你的感受是合理的。
   ```

2. **安全优先 — 使用 disclaimer-language.md 模板 4**
   ```
   🚨 紧急

   你很重要。你现在感受到的痛苦不会永远持续。有人可以帮助你。

   请立即做以下任一件事：
   1. 拨打 010-82951332（北京心理危机研究与干预中心，24小时）
   2. 拨打 400-161-9995（希望24热线）
   3. 告诉离你最近的一个人——家人、朋友、室友
   4. 前往最近的医院急诊科
   ```

3. **不要继续分析**: 在用户确认安全之前，不回到诈骗分析话题。

4. **反复确认**: 如果用户回避求助，温和地坚持：
   ```
   最重要的事是你现在的安全。分析可以等一下。
   请你打一个电话好吗？
   ```

### 非危机情况 → 继续以下流程

## 步骤 1: 情绪验证

### 目标
让用户知道他的感受是正常的、被理解的。

### 话术指导
```
发现一段你投入了感情的关系可能不是真的——这太难受了。
愤怒、悲伤、羞耻、不相信——这些感觉混在一起，是正常的。

你不是第一个遇到这种事的人，也不是最后一个。
很多人（不管男女、不论年龄、不分学历）都经历过类似的事。
愿意相信别人，说明你心里有爱——这份爱被利用了，不是你的错。
```

### 验证要点
- 不要否定用户的感受（"别难过了"）
- 不要急着给建议（先听，再共情，再建议）
- 把责任放在骗子身上，不是受害者身上
- 使用"正常化"语言——"你的反应是正常的"

---

## 步骤 2: 认知重构

### 目标
帮助用户从自责的思维模式中走出来。

### 常见认知扭曲及纠正

| 用户可能想 | 可以这样说 |
|-----------|-----------|
| "我太蠢了" | 被骗不是智商问题。杀猪盘的目标包括高管、医生、教授。骗子是专业的。 |
| "我怎么会相信" | 相信别人是一种力量。信任让你成为一个温暖的人。骗子偷走了你的信任，不是你的愚蠢。 |
| "我这辈子完了" | 你现在感觉世界塌了，这很正常。但这不是终点。很多人从类似的经历中恢复过来，甚至变得更强。 |
| "别人会怎么看我" | 你没有做错任何事。做错的是骗你的人。如果身边的人指责你而不是支持你——那是他们的问题。 |
| "我再也不相信任何人了" | 现在关上心门是正常的自我保护。给自己时间。等你准备好了，你会发现值得信任的人一直都在。 |

### 练习引导
```
如果可以的话，拿出一张纸，写下：
1. 在这段经历中，你学到了什么？
2. 这段经历让你意识到自己有哪些优点？（比如：勇敢、愿意相信别人、愿意求助——你现在就在求助）
3. 你想对一个月后的自己说什么？
```

## 步骤 3: 恢复建议

### 短期（本周）

从 `references/psychological-support.md` 中提取：

1. **稳定日常**: 保持吃饭、睡觉的基本节奏
2. **身体活动**: 每天出门走 15 分钟以上
3. **社交连接**: 告诉至少一位信任的朋友
4. **暂停交友**: 暂时卸载那个交友 App

### 中期（本月）

5. **情绪表达**: 写下来（不需要给别人看）
6. **恢复社交**: 每周至少见一位朋友
7. **保持工作/学习**: 日常结构本身有治疗作用

### 长期（三个月）

8. **反思成长**: 从经历中提取经验，但不沉浸在自责中
9. **重新定义**: 你想要什么样的关系？
10. **逐步回归**: 当你准备好时，慢慢打开自己

## 步骤 4: 专业求助指标

### 自我检查清单

提供以下清单让用户自检：
```
在过去两周中，你是否：
☐ 每天入睡困难或早醒？
☐ 完全没有胃口或一直在暴食？
☐ 对什么事都提不起兴趣？
☐ 无法集中注意力做任何事？
☐ 一直在想被骗的事，停不下来？
☐ 完全不想见任何人？
☐ 反复觉得自己"很蠢""不配被爱"？
☐ 通过喝酒来让自己麻木？

如果勾选了 ≥4 项，建议考虑找一位心理咨询师聊聊。
这不是说你有"病"——这是在照顾自己。
```

## 步骤 5: 结束语

### 温暖的结束
```
谢谢你愿意跟我说这些。
被欺骗的经历是沉重的，你能选择面对而不是回避，本身就很勇敢。

照顾好自己——这不是一句客套话。
吃饭、睡觉、出门走走，这些小事比你想的重要得多。

如果你之后需要再次分析、或者只是想聊聊，随时可以回来找我。

你值得被爱，也值得被善待。
这不是你的终点。
```

### 结束确认
- [ ] 用户情绪稳定（不再处于急性危机状态）
- [ ] 用户知道去哪里寻求更多帮助
- [ ] 用户有至少一个可以实践的恢复步骤
- [ ] 结束语温暖但不煽情
- [ ] 如果用户需要继续聊 → 不要强行结束，继续倾听
