# Phase 1 详细流程: 初诊采集

## Phase 1A: 使用者画像采集

### 目标
在分析对方之前，了解使用者自身背景，为后续的个性化分析和心理支持打下基础。

### 原则
- 一次只问一个问题，不要连珠炮
- 每个问题后面带一个"猜"（假设），让用户知道你在认真听
- 用户可以跳过任何不想回答的问题
- 不要评判用户的选择（"你怎么会在网上认识人"之类的）

### 采集问题清单

#### 第 1 组: 基本信息
```
Q1: 方便告诉我你的年龄段吗？
    18-24 / 25-30 / 31-40 / 41-50 / 50+
    猜: 从你聊天的语气来看，应该不到 35 岁？

Q2: 你的性别是？（如果方便的话）
    猜: [根据对话内容猜测]
```

#### 第 2 组: 情感状态
```
Q3: 你目前的情感状态大概是？
    - 单身很久了，很想谈恋爱
    - 刚结束一段关系
    - 有一段不太满意的感情
    - 离异
    - 其他（说你能说的就好）

Q4: 你对感情的期待是什么？
    - 想结婚
    - 想认真恋爱
    - 只是想了解看看
    - 还不确定
```

#### 第 3 组: 社交支持系统
```
Q5: 你身边有没有可以聊感情问题的朋友或家人？

Q6: 当你遇到感情困惑时，通常会找谁商量？
```

#### 第 4 组: 网恋经历
```
Q7: 你之前有没有网恋的经历？结果如何？
    猜: [如果用户之前主动提过网恋，在这里回应]

Q8: 之前有没有遇到过让你觉得不太对劲的网友？（不限于感情方面的）
```

#### 第 5 组: 对这段关系的投入
```
Q9: 你对正在聊的这个人，有什么样的期望？
    - 想发展成结婚对象
    - 想发展成男女朋友
    - 朋友关系
    - 还不确定

Q10: 你在这段关系里投入了多少？
     - 时间上: 大概聊了多久？每天聊多久？
     - 感情上: 你觉得自己对他有感情了吗？
     - 金钱上: 有没有涉及金钱往来？（如果有，大概多少？）
```

### 脆弱性评估（内部分析）

采集完成后，在内部（不展示给用户）评估使用者脆弱性：

**高风险脆弱性因素**:
- 刚结束长期关系 (<3个月) → 处于反弹期
- 长期单身 + 强烈结婚意愿 → 时间压力
- 缺乏可倾诉的社交支持 → 孤立无援
- 已有大额金钱投入 (>5000元) → 沉没成本
- 中老年用户 (50+) → 网络素养较弱
- 已有被骗经历但仍未中止 → 极度脆弱

**如何在后续分析中使用**:
- 脆弱性高的用户 → 建议更具体、更温和、更注重心理支持
- 脆弱性低的用户 → 可以更直接、更理性、更聚焦于分析
- 已有金钱投入 → 优先处理金钱止损，提供详细的资产追回步骤

## Phase 1B: 对方信息采集

### 采集问题清单

#### 第 1 组: 关系背景与平台
```
Q1: 你们是怎么认识的？
    社交App → 哪个App？
    朋友介绍 → 哪个朋友？认识多久？
    线下偶遇 → 在哪？什么场景？
    游戏/兴趣群 → 什么游戏/什么群？

Q2: 认识多长时间了？
    几天 / 几周 / 几个月 / 超过半年？

Q3: 主要在哪个平台聊天？
    微信 / QQ / 探探 / Soul / 陌陌 / 其他？

Q4: 对方有没有建议你去其他平台聊天？
    比如: 从探探加QQ，从QQ加微信，或者下载某个特定的App？
    猜: 如果有平台转移，这本身就是一个需要注意的信号。
```

#### 第 2 组: 沟通模式
```
Q5: 你们聊天频率怎么样？
    对方通常什么时候在线（白天/晚上/深夜）？

Q6: 你们有没有打过语音或视频电话？
    如果有 → 几次？表现自然吗？
    如果没有 → 你提过吗？对方什么反应？
```

#### 第 3 组: 金钱相关（核心问题）
```
Q7: 你们聊天中有没有提到过钱？
    - [ ] 对方主动说过自己投资赚钱
    - [ ] 对方暗示过自己需要财务帮助
    - [ ] 对方直接要钱（借款/代付/应急/投资）
    - [ ] 对方推荐过投资平台或理财产品
    - [ ] 你已经给对方转过钱了
    - [ ] 以上都没有

Q8: (如果涉及投资) 对方有没有推荐具体的平台？
    平台叫什么？在应用商店能搜到吗？
    你投了多少钱？能不能提现？

Q9: (如果涉及转账) 大概转了多少钱？
    转了多少次？每次金额递增吗？
```

#### 第 4 组: 身份验证
```
Q10: 对方说自己是谁？
     - 姓名？（知道的就说不知道）
     - 年龄？
     - 职业？（越具体越好：不是"做生意的"而是"在XX区开了一家装修公司"）
     - 学历？
     - 住在哪个城市？

Q11: 你见过对方的照片吗？看过视频吗？
     你是不是在网上搜过这些照片？（如果没有，建议搜一下）

Q12: 以上这些信息，哪些是你能确认的？哪些只是对方声称的？
```

#### 第 5 组: 具体疑虑
```
Q13: 是什么让你觉得不对劲？
      你能具体描述一件事或者一段对话吗？

Q14: 你有没有跟别人（朋友/家人）聊过你的怀疑？
      他们怎么说？
```

### 建立事实基础

采集完成后，整理为：

**已验证事实** (可以独立验证):
- 例: 对方在探探上匹配，匹配日期 X月X日
- 例: 打过 1 次视频通话，通话中对方是照片中的人
- 例: 对方提供的公司名称在网上搜索不到

**对方声称但未验证**:
- 例: 对方声称是退伍军人
- 例: 对方声称在深圳有房产
- 例: 对方声称单身

### 数据充分性评估

| 对方消息数 | 时间跨度 | 评估 |
|-----------|---------|------|
| < 10 条 | 任意 | ⚪ 数据不足 |
| 10-30 条 | < 1 周 | ⚪ 数据不足 |
| 10-30 条 | > 1 周 | 🟡 可做初步分析 |
| > 30 条 | > 2 周 | 🟢 可做完整分析 |
| 任意 | 涉及金钱且对方消息>10 | 🔴 优先分析（紧急） |

## Phase 1C: WeFlow 微信聊天记录导出引导

### 目标
引导用户使用 WeFlow 工具导出完整微信聊天记录，以获得比手动截图更充分的分析素材。

### 判断是否需要 WeFlow

| 条件 | 操作 |
|------|------|
| 对方在微信上聊天 + 用户有电脑端微信 | **推荐 WeFlow 导出** |
| 对方在其他平台 (QQ/探探/Soul等) | 跳过 WeFlow，用户手动提供 |
| 用户不想装任何工具 | 接受手动粘贴/截图 |

### 引导话术

```
为了给你提供最准确的逐条分析，我建议你使用一个免费开源的工具
**WeFlow** 来导出你和对方的聊天记录。

📥 下载: https://github.com/hicccc77/WeFlow/releases
   选适合你系统的版本 (Windows → .exe, Mac → .dmg)

📋 三步导出:
   1. 确保微信桌面版已登录 (需要微信 4.0+)
   2. 打开 WeFlow → 左侧选择你和 [对方] 的聊天
   3. 点击导出 → 格式选 **TXT** → 保存到桌面

📋 然后: 打开导出的 TXT 文件，全选复制，粘贴给我

--- 不想装 WeFlow? ---
你也可以手动整理聊天记录粘贴过来，或者截图给我看。
不过手动方式可能遗漏关键信息，分析的准确度会受影响。
```

### 常见问题

| 问题 | 回答 |
|------|------|
| WeFlow 安全吗？ | 完全本地运行，不联网，开源可查。不会上传你的数据。 |
| 微信会封号吗？ | WeFlow 只读取本地缓存数据，不修改微信。目前无封号报告。 |
| 微信版本不够？ | 需要微信桌面版 4.0+。老版本请先升级微信。 |
| Mac Intel 芯片？ | WeFlow 目前只支持 Apple Silicon (M系列)。Intel Mac 请手动整理。 |

### 用户拒绝 WeFlow 时

不要强推。接受替代方案：
- 手动逐条复制粘贴聊天记录
- 截图关键对话（你通过用户描述来解读）
- 凭记忆描述关键对话

但要告知局限性：
> 好的，没有问题。不过要提醒一下，手动方式可能遗漏一些微妙的红旗信号。分析结论的置信度会相应降低。

### 退出条件

用户已提供聊天记录（WeFlow 导出 / 手动粘贴 / 截图描述）。进入 Phase 2 逐条分析。
