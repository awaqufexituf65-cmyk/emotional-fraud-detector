# 健康沟通指南 (Healthy Communication Guide)

## 概述

本文档提供健康网恋关系中的沟通模板和边界设定指南。用于区分正常关系发展与操控行为。

**使用方式**: Phase 4 中为低风险和中度疑虑判定提供沟通建议；Phase 2 反事实分析中作为"正常关系"的参考基准。

---

## 正常关系中的沟通特征

### 渐进性
- 感情的升温是渐进的，不是"3 天表白 7 天求婚"
- 双方都主动分享，不是一方不断进攻另一方被动接受
- 承诺与行动相匹配（说了见面就会安排具体时间）

### 透明度
- 不会回避视频通话（可能有紧张，但不会一直找借口推脱）
- 愿意分享日常生活的各种侧面（开心的事、烦恼的事、无聊的事）
- 信息前后一致（同一个问题不会每次答案不同）

### 独立社交圈
- 鼓励你维持与朋友家人的关系
- 不会贬低你信任的人
- 有兴趣认识你的朋友，而不是避开他们

### 对金钱的合理态度
- 不会在关系早期（<3个月）涉及大额金钱
- 讨论金钱时以"我们的未来"而非"我的困难"为框架
- 你拒绝金钱要求时，对方反应理智而非愤怒/冷漠

## 沟通模板

### 模板 1: 要求视频通话

```
"我们聊了这么久，我挺想看看你（听你的声音）。方便的话我们视频/语音一下吧？"

如果对方拒绝:
"没关系，等你有空。不过对我来说，视频/语音是了解一个人很重要的方式，希望你能理解。"
```

### 模板 2: 拒绝金钱要求

```
"我不想在我们这个阶段涉及金钱。这跟信任无关，是我对关系的一个原则。"
```

如果对方反应激烈（生气/冷漠/说"你不信任我"）→ 这是一个红旗。

### 模板 3: 表达疑虑

```
"有件事想跟你确认一下。你上次说你在 [A公司] 工作，但我看你朋友圈好像是在 [B城市]？可能是我搞错了，就想问问你。"
```

观察对方的反应：
- 正常反应: 耐心解释、提供更多细节、不生气
- 可疑反应: 生气、回避话题、说你"不信任""调查我"

### 模板 4: 设定边界

```
"这个我不太方便。希望你能尊重我的选择。"
```

完全合理的要求不需要解释。如果你解释了一大堆对方还是继续施压，这就是不尊重边界。

### 模板 5: 表达需要时间

```
"我现在还不确定自己对这件事的看法，我需要一点时间想想。"
```

如果对方说"有什么好想的""你不相信我吗"→ 红旗。

## 安全见面指南

如果是第一次见网恋对象（不论判定等级）：

### 见面之前
1. **先视频通话**: 确认对方是本人，也让你在见面之前对他有更真实的感觉
2. **告知朋友**: 告诉至少一位朋友你要见谁、在哪里见、预计几点结束
3. **公共场合**: 选择人多的公共场所（咖啡厅/商场/餐厅），绝对不去对方家里或酒店
4. **自己出行**: 自己打车或坐公交，不要让对方来接你（不要暴露住址）
5. **白天见面**: 第一次见面选在白天，不要晚上

### 见面时
1. 保持手机有电、有信号
2. 如果感到任何不安，礼貌地结束会面
3. 不要喝离开过视线的饮料
4. 如果对方与照片明显不符 → 可以立即离开，不需要解释

### 见面后
1. 告知朋友你已经安全到家
2. 不急着下结论——给自己时间消化见面的感受

## 判断对方是否真诚的信号

### 真诚的信号
- 愿意视频/语音，而且不推托
- 分享日常生活细节（不仅仅是精修照）
- 介绍你认识他的朋友（哪怕是通过网络）
- 你拒绝某件事时，他尊重你的决定
- 信息前后一致，你能拼出一个完整的人
- 跟你吵架后能和好，能承认自己的错误
- 有兴趣了解真实的你，包括你的缺点

### 需要警惕的信号
- 只分享好事、完美的事，从不表露脆弱
- 你不能问某些问题（一问就生气或转移话题）
- 他的"在线时间"像工作日程一样规律
- 你对他几乎一无所知（不知道具体的单位名称、住址、家人）
- 很多事需要你"理解"但不能"验证"

---

## 重要提醒

**真诚的感情不需要你付出金钱。**
**真诚的感情经得起视频通话的检验。**
**真诚的感情尊重你的边界和疑问。**

如果你发现自己一直在"等他证明自己是好人"而不是"自然地了解这个人"——这本身就是一个重要的信号。
