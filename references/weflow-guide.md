# WeFlow 微信聊天记录导出指南

## 概述

[WeFlow](https://github.com/hicccc77/WeFlow) 是一款免费、开源、本地的微信聊天记录导出工具。它可以直接读取你电脑上的微信本地数据，将聊天记录导出为多种格式。

**本技能推荐使用 WeFlow 导出聊天记录，以便进行最全面的逐条分析。**

---

## 前提条件

| 条件 | 说明 |
|------|------|
| 微信版本 | **微信 4.0 或以上**（桌面版） |
| 操作系统 | Windows 10+ / macOS (Apple Silicon) / Linux x64 |
| 微信登录 | 需要在电脑上登录过微信，产生本地数据 |

> ⚠️ 如果你使用的是微信 3.x 或更早版本，请先升级微信桌面版到 4.0+。

---

## 安装步骤

### Windows

1. 打开 https://github.com/hicccc77/WeFlow/releases
2. 下载最新的 `WeFlow_x.x.x_windows_amd64.exe`
3. 双击运行（可能会弹出 Windows Defender 警告，点"更多信息"→"仍要运行"）
4. WeFlow 会自动检测微信数据目录

### macOS

1. 打开 https://github.com/hicccc77/WeFlow/releases
2. 下载最新的 `WeFlow_x.x.x_macos_arm64.dmg`
3. 安装后，首次打开时在"系统设置 → 隐私与安全性"中允许运行

### Linux

```bash
# ArchLinux
yay -S weflow

# 其他发行版
# 下载 AppImage 或 tar.gz 后解压运行
```

## 导出聊天记录

### 步骤

1. **打开 WeFlow**，它会显示你的微信联系人列表
2. **选择你要分析的联系人**（点击左侧联系人列表）
3. **查看聊天记录**是否完整加载（可以滚动浏览）
4. **导出**：
   - 点击导出按钮
   - 选择格式：**推荐 TXT**（纯文本，方便粘贴分析）或 **JSON**（结构化数据）
   - 选择时间范围：建议导出**全部**聊天记录
   - 保存文件到你知道的位置（比如桌面）
5. **打开导出的文件**，复制全部内容

### 推荐导出格式

| 格式 | 适合场景 |
|------|---------|
| **TXT** | 最推荐 — 直接复制粘贴到对话中，保留文本和时间戳 |
| **JSON** | 适合结构化分析 — 包含每条消息的时间、发送者、消息类型 |
| **HTML** | 适合自己浏览查看 |
| **Excel/CSV** | 适合统计数据（消息频率、时间段分布等） |

---

## 复制聊天记录到对话中

导出为 TXT 后，文件内容类似：

```
2026-01-15 14:23:01 对方: 你好，很高兴认识你
2026-01-15 14:23:45 你: 你好！
2026-01-15 14:24:12 对方: 你平时喜欢做什么呀
...
```

**直接全选复制**，粘贴到对话中即可。本技能会自动解析时间线和发送者。

## 隐私与安全

| 项目 | 说明 |
|------|------|
| **本地运行** | WeFlow 完全在你的电脑上运行，不会上传任何数据 |
| **开源代码** | 代码在 GitHub 上公开，可自行审查 |
| **本技能** | 分析仅在当前 Claude Code 会话中进行，不保存、不传输 |

> ⚠️ 导出的聊天记录包含私密内容。请妥善保管导出的文件，分析完成后建议删除。

## 常见问题

### Q: WeFlow 打不开/闪退？
A: 检查微信是否已登录（桌面版），确保微信版本 ≥ 4.0。重启微信和 WeFlow 试试。

### Q: 聊天记录加载不出来？
A: 可能是因为微信数据目录权限问题。在 WeFlow 设置中检查微信数据路径是否正确。

### Q: 不想装 WeFlow？
A: 你也可以手动整理聊天记录——截图或逐条复制粘贴到对话中。但手动方式覆盖不全面，可能遗漏关键红旗。

### Q: WeFlow 支持 macOS Intel 芯片吗？
A: 目前只支持 Apple Silicon (M 系列)。Intel Mac 用户建议手动整理聊天记录。

### Q: 用 WeFlow 会被微信封号吗？
A: WeFlow 只是读取本地已解密的数据，不修改微信进程，不发送网络请求。目前没有因使用 WeFlow 被封号的报告。但任何第三方工具都有风险，使用前请了解并自行承担。
