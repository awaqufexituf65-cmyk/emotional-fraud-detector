# 心理操控手法分类学 (Psychological Manipulation Taxonomy)

## 概述

本文档收录了情感诈骗和不良关系中常见的心理操控手法。每种手法包含：定义、在文字聊天中的表现、示例对话（匿名化）、正常关系中的对应表现（反例）。

**使用方式**: 在 Phase 2 步骤 2 中，逐项检查用户对话中是否存在这些操控手法，标注具体实例和出现频次。

**理论基础**: Cialdini 影响力原理 (2001)、Forward & Frazier 情感勒索理论 (1997)、Stines 煤气灯效应研究 (2021)。

---

## 手法 1: 爱情轰炸 (Love Bombing)

### 定义
在认识初期，以超乎寻常的强度和频率表达爱意、赞美和承诺，目的是快速建立情感依赖。

### 在线聊天中的表现
- 认识不到 1 周就开始叫"宝贝""老公/老婆"
- 每天早上/晚上准时的长篇"甜言蜜语"
- 不断夸你是"最特别的""从来没见过像你这样的人"
- 快速谈论婚姻、孩子、未来生活（认识不到 1 个月）
- 送大量虚拟礼物（微信红包、礼物表情包）
- 说"我从来没有对别人有过这种感觉"

### 示例（匿名化）
```
认识第 3 天:
对方: "你知道吗，我感觉我找到了一直在等的人"
对方: "你就是我想要过一辈子的人"
对方: "我会让你成为世界上最幸福的女人"
```

### 正常关系中的表现
- 好感是渐进式的，不会在第 3 天就谈结婚
- 赞美是具体的（"你今天的分享很有趣"而不是"你是完美的"）
- 未来计划是一起讨论的，不是单方面承诺的

### 判定要点
- **频率**: 每天都大量表白 → 高可疑
- **速度**: 认识 <1 周就谈结婚 → 高可疑
- **内容**: 过度抽象、完美化（"你是完美的"）→ 可疑

## 手法 2: 画大饼 (Future Faking)

### 定义
不断给出关于未来的承诺和计划，但从未兑现。目的是让受害者活在对未来的想象中，忽略当下的危险信号。

### 在线聊天中的表现
- "我们结婚后..."
- "等我忙完这一阵，我就..."
- "我计划下个月去找你"（说了很多次但从没实现）
- 每次你质疑关系时，就抛出新的未来计划
- 所有的承诺都缺乏具体细节（没有具体日期、具体计划）

### 示例（匿名化）
```
用户: "我们认识这么久了，什么时候能见个面？"
对方: "宝贝我也很想见你，但是最近项目太忙了。下个月我一定去找你，我保证！"
（下个月到了）
对方: "我护照出了点问题...再等我一下好吗，我真的很想见你"
```

### 正常关系中的表现
- 计划是双向的、有具体步骤的
- 承诺会兑现，如果无法兑现会主动解释并道歉
- 不会把所有"好事"都推到未来

## 手法 3: 孤立 (Isolation)

### 定义
有意或无意地减少受害者与朋友、家人及其他支持系统的联系。

### 在线聊天中的表现
- "你朋友都不懂我们的感情"
- "你为什么总跟他们说我们的事？"
- "他们只是嫉妒我们"
- "你不要什么都告诉你爸妈"
- 每当你和朋友见面后，对方就变得冷淡或生气
- 暗示你应该把更多时间留给他

### 示例（匿名化）
```
用户: "我闺蜜说让我小心一点，毕竟你还没见过面"
对方: "你闺蜜根本就不了解我们。她是不是嫉妒你找到这么好的男朋友？"
对方: "以后我们的事不要跟外人说，别人不理解"
```

### 判定要点
- 鼓励与朋友家人疏远 → 高风险
- 贬低你信任的人 → 高风险
- 正常关系中，伴侣会鼓励你维持独立的社交圈

## 手法 4: 情感绑架 (Guilt Tripping)

### 定义
利用内疚感和亏欠感来操控对方的行为。

### 在线聊天中的表现
- "我为你付出了这么多..."
- "要不是因为我爱你..."
- "你怎么忍心这样对我"
- "我那么信任你"
- 把自己置于"受害者"位置，让你觉得亏欠
- 用自残或抑郁来威胁（"如果你不理我，我不知道自己会做出什么"）

### 示例（匿名化）
```
你拒绝了对方的转账请求:
对方: "我把我所有的心都给了你，你连这个都不愿意接受？"
对方: "算了，我习惯了不被人在乎。我这种人就是不该有人爱"
```

### 判定要点
- 用自我贬低来获得你的同情和让步 → 高风险
- 用威胁自残来控制你 → 极度危险，建议对方立即寻求专业帮助，同时保护自己

## 手法 5: 冷热交替 (Intermittent Reinforcement)

### 定义
交替提供热情和冷漠，制造不可预测性，让受害者"上瘾"。

### 在线聊天中的表现
- 某段时间非常热情，突然消失几天
- 回来后若无其事或有"完美"的解释
- 冷淡的时候你感到焦虑，热的时候你感到解脱
- 你发现自己不断查看手机等他回复
- 回复时间从秒回到小时到天，越来越不可预测

### 判定要点
- 间歇性消失 + 回来后不解释或解释过度 → 可疑
- 这让你产生了"他迟早会回来"的期待 → 正在形成依赖
- 正常关系中，回复时间基本稳定，消失会提前告知

## 手法 6: 煤气灯效应 (Gaslighting)

### 定义
通过否认事实、扭曲记忆，让受害者怀疑自己的判断力。

### 在线聊天中的表现
- "我没有说过那种话，你记错了"
- "你太敏感了"
- "这都是你自己想的，我从来没这么做过"
- "你又胡思乱想了"
- 删除或撤回消息后声称从未发过
- 把你的合理质疑说成"不信任""在测试我"

### 示例（匿名化）
```
你: "你上次说你住在深圳，现在怎么说是广州？"
对方: "我什么时候说过深圳？你肯定记错了。我一直说的是广州"
你: [截图聊天记录]
对方: "哎呀我那天在深圳出差，口误而已。你这都不信我？"
```

### 判定要点
- 否认可查证的对话内容 → 高风险
- 对你的合理疑问进行贬低（"你太敏感了"）→ 高风险

## 手法 7: 制造紧迫感 (Urgency Creation)

### 定义
制造虚假的时间压力，让你在来不及思考的情况下做决定。

### 在线聊天中的表现
- "今天必须决定，不然就来不及了"
- "这个投资机会只有 24 小时"
- "你再不转账我就不理你了"
- "医生说我需要马上动手术"
- 所有的事情都是"紧急"的

### 判定要点
- 正常关系中，真正重要的事经得起时间斟酌
- 任何催促你做重大决定（特别是涉及金钱）的行为 → 高风险

---

## 手法 8: 创伤纽带 (Trauma Bonding)

### 定义
通过一起经历"困难"来建立情感连接——这些困难往往是一方制造的。

### 在线聊天中的表现
- 编造共同的"敌人"（不理解的家人/朋友圈子）
- 一起经历他制造的危机（"别人都在针对我""这个世界不理解我"）
- "只有你才懂我，我们一起面对"

### 判定要点
- 你们的关系建立在"对抗外界"之上 → 可疑
- 正常关系建立在共同兴趣和价值观上，不是共同的敌人

---

## 综合判定

对于每个识别出的操控手法，记录：
- **手法名称**
- **证据**: 从聊天中摘抄的 1-2 句原文
- **出现时间**: 在关系中的哪个阶段
- **频次**: 出现次数
- **严重程度**: 轻度/中度/严重

严重程度判定：
- **严重**: 手法+涉及金钱+隔离+煤气灯效应+威胁自残
- **中度**: 多次操控手法，但不涉及金钱
- **轻度**: 偶发的可疑行为，不构成明显模式
