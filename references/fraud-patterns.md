# 情感诈骗模式目录 (Fraud Pattern Catalog)

## 概述

本文档收录了中文互联网上最常见的情感诈骗模式。每种模式包含：核心特征、典型时间线、关键行为标记、示例对话模式。

**使用方式**: 在 Phase 2 步骤 1 中，逐项对照用户的聊天记录，检查是否匹配 ≥3 个核心特征。

**来源**: 中国公安部反诈中心公开资料、澎湃新闻/央视反诈报道、学术论文(网络诈骗心理学)、各大平台反诈公告。

---

## 类型 1: 杀猪盘 (Pig-Butchering Scam)

### 概述
"杀猪盘"是目前最常见、涉案金额最大的情感诈骗类型。诈骗者长期培养感情（"养猪"），然后诱导受害者进入虚假投资/赌博平台（"杀猪"）。

### 作案平台
探探、Soul、陌陌、世纪佳缘、百合网 → 引导至微信/QQ → 引导至虚假投资App

### 典型时间线
```
第 1-7 天:  匹配 + 日常聊天，建立基本信任
第 7-14 天: 深入情感交流，确立"恋爱关系"，频繁互称"老公/老婆"
第 14-21 天: 不经意向你提及"副业"/"理财"/"投资"
第 21-28 天: 展示高收益截图，建议你"小试一下"
第 28-35 天: 你投入小额，对方帮你提现（制造信任）
第 35+ 天:   诱导你投入大额，然后平台无法提现，对方消失
```

### 核心特征 (需要 ≥3 项匹配)

1. **身份包装完美**: 照片精致（通常是盗用的网红/模特图），条件优越（高收入/有房有车/家境好），但都是自述，无法验证
2. **快速建立亲密关系**: 认识不久就开始叫"宝贝""老公/老婆"，频繁表达爱意和未来计划（结婚/买房/一起旅行）
3. **有固定"在线时间"**: 每天固定时间段聊天（他们在"上班"——骗人），但从不打视频电话
4. **拒绝视频通话**: 找各种理由（摄像头坏了/在部队不能视频/在出差/信号不好）
5. **有投资/理财背景**: 声称自己做金融、或者有"朋友"在交易所工作、或者自己研究出了一套稳赚的方法
6. **科技产品故障**: 手机经常坏、账号经常被盗、总是各种技术理由不能视频
7. **展示有闲有钱的生活**: 朋友圈/动态展示高品质生活（美食/旅游/名车），但时间线可疑
8. **引导下载不明 App**: 要求你下载某个特定的投资/聊天 App，不在主流的应用商店
9. **让你尝到甜头**: 小额投资可以提现，大额后无法提现
10. **制造紧迫感**: "这个投资机会马上没了""今晚必须入金"

### 关键对话模式

**阶段 1 — 建立信任**
```
对方: "你好，很高兴认识你 😊"
对方: "我看你的资料，感觉你是个很善良的人"
对方: "能在这个平台上遇到你，真的很幸运"
```

**阶段 2 — 情感升温**
```
对方: "宝贝，跟你在一起的这段时间，是我最开心的日子"
对方: "我一直在想，如果能和你结婚，该多好"
对方: "我已经跟我妈说起你了"
```

**阶段 3 — 投资铺垫**
```
对方: "今天工作好累，不过副业赚了点钱，还挺开心的"
对方: "我一个朋友在交易所做技术，他会给我一些内幕消息"
对方: "你要不要也试一下？不用投太多，先试试看"
```

**阶段 4 — 收割**
```
对方: "宝贝相信我，这次机会真的很难得"
对方: "你把钱都投进去吧，明天就能翻倍"
对方: "我在想办法帮你，你别急"（提现失败之后）
```

## 类型 2: 冒充军人/医生 (Fake Authority Figure)

### 概述
诈骗者冒充军人、医生、工程师等社会地位较高的职业，利用用户对这些职业的信任进行诈骗。

### 核心特征

1. 声称自己是军人/医生/联合国工作人员/海外工程师
2. 照片穿制服，看起来专业可靠
3. 声称在海外服役/执行任务/维和（无法见面的合理借口）
4. 在关系建立后，突然出现紧急事件：
   - 执行任务受伤需要医疗费
   - 需要购买回国机票
   - 包裹被海关扣押需要清关费
   - 战友/同事出事需要紧急用钱
5. 声称自己账户被冻结/在战地无法使用银行卡
6. 要求你帮忙接收包裹/代为付款
7. 承诺"回国就和你结婚"，利用感情和承诺施压

### 关键对话模式
```
对方: "我在XX国执行维和任务，这里条件很艰苦..."
对方: "我给不了你陪伴，但我可以给你一个承诺"
对方: "[突然]出事了，我受伤了，需要一笔医疗费，我账户被冻结..."
```

## 类型 3: 裸聊敲诈 (Sextortion)

### 概述
诱导用户进行视频裸聊，录制后以发送给通讯录好友为威胁，实施敲诈勒索。

### 核心特征

1. 聊天过程中快速引导至私密话题
2. 要求下载指定的"私密聊天 App"（实为获取通讯录的木马）
3. 主动提出视频裸聊邀请
4. 录制用户裸聊视频
5. 发送用户通讯录截图，威胁如果不给钱就把视频发给所有联系人
6. 持续勒索，每次说"最后一次"，但永无止境

### 高危信号
- 对方主动要求视频通话，且暗示/明示裸聊
- 要求下载某个"更私密"的聊天软件
- 聊天 App 申请通讯录权限（正常聊天 App 不需要）

## 类型 4: 投资导师型 (Investment Mentor Scam)

### 概述
假装对你有好感的同时，不断分享自己的"投资心得"，本质上是金融诈骗。

### 核心特征

1. 聊天中以"分享"的名义频繁提到自己的投资收益
2. 朋友圈/动态经常晒收益截图（大金额、高收益率）
3. 推荐加入投资群/添加"分析师"微信
4. "我帮你看看，不会有风险的"
5. 引导至不知名的虚拟货币交易所或"场外"投资平台
6. 声称可以通过"内部渠道"或"技术漏洞"获得超额收益
7. 初期允许小额提现，后期无法提现

## 类型 5: 跨国包裹诈骗 (Parcel Scam)

### 概述
诈骗者声称自己在海外（美国/英国/澳大利亚等），要寄"贵重包裹"给你，然后要求你支付各种费用。

### 核心特征

1. 声称在国外工作/出差（军人、工程师、商人常见）
2. 说给你寄了一份"贵重的礼物"（首饰/包包/现金/重要文件）
3. 包裹被海关扣押、需要清关费
4. 要求你支付"清关费""保证金""税金"等
5. 每次付了一个费用，又会出现新的费用
6. 对方声称自己暂时无法支付（卡被冻结/在国外不方便）

---

## 类型 6: 紧急事件型 (Emergency Scam)

### 概述
建立感情后，编造突发紧急事件索要钱财。

### 核心特征

1. 突然出现"紧急情况": 自己/家人生病、出车祸、被抢劫
2. 需要立刻汇款
3. 制造紧迫感: "不马上转钱就来不及了"
4. 阻止你向其他人咨询: "没时间了""你先帮我，回头再解释"
5. 金额从几千到几万不等，看起来"有零有整"（显得真实）

---

## 类型 7: 往返型/幽灵型 (Intermittent Scam)

### 概述
利用间歇性强化原理，反复出现和消失，让人产生依赖。

### 核心特征

1. 聊得火热时突然消失（几天到几周）
2. 回来时有精心准备的"合理"解释
3. 每次回来都比之前更热情
4. 让人产生"他迟早会回来"的期待
5. 可能在多次往返后开始索要好处

## 匹配评估方法

对每种适应的诈骗类型，按以下维度评估：

| 匹配度 | 标准 |
|--------|------|
| **完全匹配** | ≥3 个核心特征 + 对话模式高度吻合 |
| **部分匹配** | 1-2 个核心特征吻合，或有类似但不典型的模式 |
| **无匹配** | 不满足任何核心特征 |

**注意**: 新型诈骗手法不断出现。如果用户的经历不完全匹配以上任何类型，但红旗评分高，应如实告知用户："这可能是一种不在我已知数据库中的新型诈骗手法。"
