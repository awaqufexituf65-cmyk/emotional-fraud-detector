# 风险红旗分级清单 (Red Flags Checklist)

## 概述

本文档提供了系统化的红旗评分体系。每个红旗按严重程度分为 P0-P3 四个等级，加权计入综合评分。

**使用方式**: 在 Phase 2 步骤 3 中，逐项对照检查，统计各等级红旗数量，计算综合评分。

---

## P0 级红旗 (致命 — 几乎确定是诈骗)

**命中 1 项即触发高风险标记。权重: 25 分/项**

| # | 红旗 | 说明 | 检查 |
|---|------|------|------|
| P0-1 | 要求转账到陌生账户 | 对方提供了不属于本人（或无法验证身份）的银行账号 | ☐ |
| P0-2 | 诱导下载不明投资/赌博 App | 不在主流应用商店，或下载链接可疑 | ☐ |
| P0-3 | 要求提供银行卡号/验证码/身份证照片 | 此类信息一旦泄露可被用于盗刷 | ☐ |
| P0-4 | 投资/理财平台无法提现 | 已投入资金但无法取回 | ☐ |
| P0-5 | 以发送私密内容为威胁进行敲诈 | 裸聊敲诈、隐私敲诈 | ☐ |
| P0-6 | 声称遭遇重大紧急事件要求立即汇款 | 冒充军人/医生/海外亲属求救 | ☐ |

---

## P1 级红旗 (高危 — 强烈指向诈骗)

**权重: 10 分/项**

| # | 红旗 | 说明 | 检查 |
|---|------|------|------|
| P1-1 | 身份信息前后矛盾 | 今天说住A城市，明天说B城市；职业/学历前后不一致 | ☐ |
| P1-2 | 多次回避视频或语音通话 | 总是有理由不打视频，但文字聊天频繁 | ☐ |
| P1-3 | 快速表白和承诺未来（<1周） | 认识不到一周就开始谈婚论嫁、叫老公/老婆 | ☐ |
| P1-4 | 引导至非主流聊天平台 | 从一个平台刻意引导到另一个平台（如从探探到QQ） | ☐ |
| P1-5 | 主动展示高收益投资截图 | 声称自己有稳赚不赔的投资方法 | ☐ |
| P1-6 | 照片在网络上搜索到多处出现 | 对方发的"自拍"其实是被盗用的图 | ☐ |
| P1-7 | 编造"特殊身份" | 军人/医生/联合国人员/海外工程师 | ☐ |
| P1-8 | 声称银行账户被冻结/无法自行支付 | 需要你帮忙付款，之后"还你" | ☐ |
| P1-9 | 要求发送私密照片/视频 | 以满足欲望为名，实为收集敲诈素材 | ☐ |

## P2 级红旗 (中危 — 值得警惕)

**权重: 4 分/项**

| # | 红旗 | 说明 | 检查 |
|---|------|------|------|
| P2-1 | 个人背景信息过于模糊 | 问工作说"做生意"，问收入说"还行"，问具体就转移话题 | ☐ |
| P2-2 | 朋友圈/动态与声称身份不匹配 | 朋友圈内容与声称的职业/生活方式明显矛盾 | ☐ |
| P2-3 | 接触时间总是对方"刚好有空" | 对方似乎没有正常的工作和生活节奏 | ☐ |
| P2-4 | 每天定时聊天但从不打视频 | 像上班打卡一样的规律，但有合理视频回避 | ☐ |
| P2-5 | 引导情感依赖后开始冷淡 | 热情→缺失→更热情的模式，制造焦虑和依赖 | ☐ |
| P2-6 | 照片总是过于精致完美 | 每次发的照片都是专业级摆拍，不像日常生活随拍 | ☐ |
| P2-7 | "刚好"遇到各种困难 | 总是在你觉得关系不错的时候遇到"困难"需要帮助 | ☐ |
| P2-8 | 阻止你咨询他人意见 | 说"我们的事不要告诉别人""别人不懂我们" | ☐ |
| P2-9 | 过度打探你的财务状况 | 问收入、问存款、问房产、问负债，比你自己还关心你的钱 | ☐ |

## P3 级红旗 (低危 — 可能需要留意)

**权重: 1 分/项，不纳入主要评分，作为辅助参考**

| # | 红旗 | 说明 |
|---|------|------|
| P3-1 | 语法/用词与声称学历不符 | 声称985硕士但聊天全是错别字和小学语法 |
| P3-2 | 头像过于完美（像模特图） | 可与P1-6配合：搜图验证后升级为P1 |
| P3-3 | 从不分享具体日常生活 | 照片全是精修照，没有"随手拍"的生活瞬间 |
| P3-4 | 回复时间总是在固定时段 | 每天只在某个时段聊天，其他时间"消失" |
| P3-5 | 对话中包含大量模板化情话 | 情感表达过于流畅和重复，像复制粘贴 |

## 评分公式

```
综合分数 = (P0命中数 × 25) + (P1命中数 × 10) + (P2命中数 × 4)

数据调整因子:
- 对方消息 < 10 条: × 0.5 (数据不足，分数打折扣)
- 对方消息 10-30 条: × 0.8
- 对方消息 > 30 条: × 1.0
- 涉及已实际转账: × 1.5 (紧急因子)
```

### 分数与判定对应表

| 综合分数 | 判定方向 |
|----------|---------|
| ≥ 25 分 | 🔴 高风险 — 高度疑似诈骗 |
| 10 - 24 分 | 🟠 中高风险 — 强烈建议警戒 |
| 4 - 9 分 | 🟡 中度疑虑 — 需要进一步验证 |
| < 4 分 | 🟢 低风险 — 可能为正常交往 |

**特别规则**:
- 不论总分多少，P0 ≥ 1 → 自动升级为至少 🟠 中高风险
- 不论总分多少，已实际转账 + P0 ≥ 1 → 自动升级为 🔴 高风险
- P0 = 0 且 P1 = 0 且 P2 < 2 → 必须进行充分的反事实分析后再判定

## 重要警示

1. **假阴性风险**: 没有红旗 ≠ 安全。高明的诈骗者可以长期不留明显破绽。
2. **假阳性风险**: 有红旗 ≠ 一定是骗子。神经多样性（如 ADHD 导致的回复不稳定）、跨文化沟通、第二语言使用等都可能产生"假红旗"。
3. **贝叶斯思维**: 红旗评分是概率信号，不是确定性证据。结合整体模式、一致性和反事实分析综合判断。
4. **及时更新**: 诈骗手法不断进化。遇到无法匹配本清单但直觉可疑的情况，应如实告知用户。

---

## 使用指导

1. Phase 2 分析过程中，边阅读聊天记录边对照本清单逐项打勾
2. 每勾选一项，记录对应的聊天内容原文（至少 1 句）作为证据
3. 分析完成后计算综合分数
4. 分数结合 Phase 3 判定矩阵综合使用
5. 在输出结果中，列出得分项和对应的证据引用
