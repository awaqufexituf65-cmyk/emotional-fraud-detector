# 逐条消息深度分析方法论 (Per-Message Analysis)

## 概述

v2.0 的核心升级：从"整体看这段关系像不像诈骗"升级为"**每一段对话在说什么、想达到什么目的、有什么风险**"。

逐条分析让你能够：
- 看到诈骗行为的**渐进式演变**——第一周和第十周的区别
- 识别**微妙的操控信号**——单条消息可能看起来正常，但放在序列中就是操控
- 给用户提供**具体的应对方案**——"当时他说这句话的时候，你应该这样回"

---

## 七维分析框架

分析每一条（或每一小段）对方消息时，从以下七个维度解读：

### 1. 字面含义
**回答**: 这条消息在字面上说了什么？

- 把对方的原话翻译成最直白的表述
- 不要过度解读，先忠实描述字面意思
- 例: "宝贝你今天真好看" → 字面含义: 在称赞你的外貌

### 2. 潜在意图
**回答**: 对方发这条消息的真正目的是什么？

- 区分"说了什么"和"想达到什么"
- 常见意图类别:
  - **建立信任**: 让对方感觉被理解、被关心
  - **测试服从**: 看对方会不会答应一个小请求
  - **收集信息**: 打探财务、家庭、社交圈
  - **制造依赖**: 让对方习惯自己的存在和赞美
  - **推进关系**: 加速感情升温
  - **铺垫金钱**: 为后续的投资/借钱做舆论准备
  - **收割/施压**: 直接要钱或制造紧迫感
  - **维持控制**: 对方产生怀疑时进行安抚或打压
- 例: "宝贝你今天真好看" → 潜在意图: 建立情感依赖，让对方习惯被赞美

### 3. 操控手法
**回答**: 这条消息使用了哪种心理操控手法？

对照 `references/manipulation-tactics.md`:
- 爱情轰炸 (Love Bombing)
- 画大饼 (Future Faking)
- 孤立 (Isolation)
- 情感绑架 (Guilt Tripping)
- 冷热交替 (Intermittent Reinforcement)
- 煤气灯效应 (Gaslighting)
- 制造紧迫感 (Urgency Creation)
- 创伤纽带 (Trauma Bonding)
- **无** — 本条消息未检测到操控手法

### 4. 红旗等级
**回答**: 本条消息触发什么级别的风险红旗？

对照 `references/red-flags-checklist.md`:
- 🔴 P0 (致命): 直接索要钱财/诱导下载不明App/索要银行卡信息
- 🟠 P1 (高危): 快速表白/回避验证/身份矛盾
- 🟡 P2 (中危): 信息含糊/过度赞美/打探财务
- ⚪ P3 (低危): 语法可疑/头像过于完美
- **无** — 本条消息无红旗

### 5. 情绪策略
**回答**: 对方使用什么情感基调来影响你？

- **温暖/甜蜜**: 让你感到被爱、被珍视 → 建立情感依赖
- **紧迫/焦虑**: 制造时间压力 → 让你来不及思考
- **内疚/亏欠**: 让你觉得对不起他 → 操控你的行为
- **恐惧/威胁**: 让你害怕失去他或害怕后果 → 逼你服从
- **炫耀/展示**: 展示财富/能力/品味 → 建立权威感和可信度
- **脆弱/求助**: 把自己塑造成需要帮助的人 → 激发你的保护欲
- **理性/专业**: 用"专业分析"包装投资建议 → 降低你的戒心
- **冷漠/疏远**: 突然冷淡 → 制造焦虑和依赖（间歇性强化）
- **中性** — 普通聊天，无明显情绪操控

### 6. 关系阶段
**回答**: 在诈骗时间线中，这条消息处于哪个阶段？

- **初步接触**: 打招呼、基本信息交换
- **感情升温**: 甜言蜜语、确立关系、未来承诺
- **信任构建**: 深度情感交流、小额验证（如小额投资成功提现）
- **金钱铺垫**: 不经意向你展示投资收益、提到"财务自由""我们的未来"
- **收割**: 直接引导大额投入、制造紧迫感
- **维持/善后**: 出现问题后安抚、解释、推脱、继续施压
- **失联**: 不再回复、注销账号
- **正常关系**: 不适用诈骗时间线分类（用于正常交往的分析）

### 7. 应对建议
**回答**: 如果用户当时收到这条消息，最合理的做法是什么？

- **接受**: 这条消息完全正常，正常回应即可
- **观察**: 这条消息有一定可疑，记下来，继续观察后续
- **验证**: 这条消息涉及关键信息（身份/职业/经历），应该验证
- **设定边界**: 这条消息越界了（太快/太私密/涉及金钱），应该礼貌但坚定地拒绝
- **停止**: 这条消息明确触发红旗，应该停止互动
- **报警**: 涉及明确诈骗行为，保留证据并报警

## 分析输出格式

对每一条或每一段对方消息，使用以下格式输出：

```markdown
### 📩 第 N 段 — [时间/阶段]

**对方**: > "[原文引用]"

| 维度 | 分析 |
|------|------|
| 💬 字面含义 | [对方在说什么] |
| 🎯 潜在意图 | [对方真正想达到什么目的] |
| 🧠 操控手法 | [操控手法名称] 或 **无** |
| 🚩 红旗等级 | 🔴P0 / 🟠P1 / 🟡P2 / ⚪P3 / **无** |
| 🎭 情绪策略 | [温暖/紧迫/内疚/恐惧/炫耀/脆弱/理性/冷漠/中性] |
| 📍 关系阶段 | [阶段名称] |
| 💡 当时该怎么回 | [具体建议] |
```

## 逐条分析示例

### 示例 1: 爱情轰炸

**对方**: > "你知道吗，遇见你可能是今年最好的事了。我开始认真想我们的将来了。"

| 维度 | 分析 |
|------|------|
| 💬 字面含义 | 表达遇见你很开心，在考虑和你的未来 |
| 🎯 潜在意图 | 加速感情升温，让你产生"他是认真的"的错觉 |
| 🧠 操控手法 | **爱情轰炸 + 画大饼** — 认识不到一周就谈"将来" |
| 🚩 红旗等级 | 🟠 P1 — 快速表白和承诺未来 |
| 🎭 情绪策略 | 温暖/甜蜜 — 让你感到自己被珍视 |
| 📍 关系阶段 | 感情升温期 |
| 💡 当时该怎么回 | "谢谢你的心意，但我觉得我们还是先多了解彼此。未来的事慢慢来。" |

---

### 示例 2: 投资铺垫

**对方**: > "宝贝，我今天工作上有点累，不过副业赚了点，心情好多了。就是一个朋友在交易平台做技术，会给我一些内部消息。"

| 维度 | 分析 |
|------|------|
| 💬 字面含义 | 工作累但副业赚钱了，有朋友在交易平台工作 |
| 🎯 潜在意图 | 铺垫投资话题，测试你对"轻松赚钱"的兴趣；"内部消息"增加可信度 |
| 🧠 操控手法 | **炫耀 + 画大饼** — 展示赚钱能力，暗示你也可以参与 |
| 🚩 红旗等级 | 🟡 P2 — 主动展示投资/副业收益 |
| 🎭 情绪策略 | 炫耀/展示 + 脆弱（"工作累"）— 双轨并行，既有权威感又有亲近感 |
| 📍 关系阶段 | 金钱铺垫期 — 感情升温完成，开始进入收割前奏 |
| 💡 当时该怎么回 | "了解了。不过我对投资不太懂，目前没有这个打算。你的副业听起来不错，祝你顺利。" |

## 分析节奏

### 分组原则
- 如果聊天记录很长（>30条对方消息），按**时间阶段**分组——每周或每个关系转折点为一段
- 每段的分析聚焦于**最有代表性的 3-5 条消息**——不需要逐字分析每一条"早安""晚安"
- 关键转折点的消息**必须逐条分析**：第一次表白、第一次提钱、第一次拒绝视频等

### 重点标注
- 🔥 标注为**关键转折点**的消息——这条消息之后，关系性质发生了变化
- ⚠️ 标注为**应立即停止**的消息——触发 P0 红旗
- ❤️‍🩹 标注为**情感操控**的消息——不使用逻辑而使用情绪操控

## 整体模式总结

完成所有逐条分析后，输出一段总结：

```markdown
## 📊 整体模式总结

### 关系发展曲线
[描述从认识到现在的整体发展轨迹]

### 红旗时间线
- 第 1 周: [红旗情况]
- 第 2 周: [红旗情况]
- ...

### 操控手法分布
- 爱情轰炸: 3 次 (第1、2、4周)
- 画大饼: 5 次 (第3-8周持续)
- ...

### 阶段判定
这段关系整体处于: [感情升温期 → 金钱铺垫期 → 收割期 → ...]

### 关键转折点
1. [日期/阶段]: [转折描述]
2. ...

### 综合评价
[2-3 句话整体评价，承上启下，为 Phase 3 判定做铺垫]
```

## 使用指导

1. 逐条分析时要**客观、具体、有证据**——每条分析引用对方原文
2. 不要因为"前面已经有红旗"就默认后面的消息也有问题——每条独立分析
3. 标注"无红旗/无操控手法"也是重要的——它让正常消息和红旗消息形成对比
4. 应对建议要**可操作**——不是"小心一点"而是"你这样回：..."
