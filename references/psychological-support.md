# 心理恢复与支持指南 (Psychological Recovery Guide)

## 概述

本文档为发现情感欺骗后的心理恢复提供结构化支持。用于 Phase 5 心理支持阶段。

**重要声明**: 本文档提供的是心理教育和支持性建议，不构成临床心理治疗。危机情况请拨打专业热线。

---

## 情感欺骗后的常见心理反应

以下反应都是正常的，不代表你"脆弱"或"有问题"：

### 第一阶段: 震惊与否认（通常持续数小时到数天）
- 难以置信——"这不会发生在我身上"
- 反复查看聊天记录，试图找证据证明"这不是真的"
- 身体反应（胸闷、失眠、食欲不振）
- 想要再给一次机会，等对方解释

### 第二阶段: 愤怒与悲伤（通常持续数周到数月）
- 对骗子的愤怒——"他怎么可以这样"
- 对自己的愤怒——"我当初怎么没看出来"
- 深深的悲伤——对失去的关系、时间和金钱
- 羞耻感——不敢告诉家人朋友

### 第三阶段: 接受与重建（时间因人而异）
- 能够回顾经历而不被情绪淹没
- 重新建立对他人和自己的信任
- 将经历整合为人生经验
- 开始新的社交和情感生活

## 认知重构练习

### 练习 1: 责任归属
```
被骗的责任在骗子，不在受害者。
骗子的工作是骗人，他们是训练有素的专业人员。
愿意相信别人是一种美好的品质，不是愚蠢。
```

如果你发现自己一直说"我当初应该...":
试着对自己说: "我当时掌握的信息不足以做出更好的判断。"

### 练习 2: 证据 vs 感觉
```
写下来：
1. 有哪些具体的事情（言行）让你当时觉得对方可信？
2. 有哪些事情你现在回头看觉得不对劲？
3. 从这份经历中，你学到了什么可以帮助未来的自己？
```

### 练习 3: 区分"信任"和"验证"
```
信任是给予的，验证是必要的。
在网上认识的人：验证身份不是不信任，是自我保护。
下次：先视频、先搜图、先告诉朋友、再考虑信任。
```

## 自我恢复行动计划

### 第 1 周: 稳定
- [ ] 每天按时吃饭、睡觉（哪怕没胃口、睡不着）
- [ ] 每天出门走 15 分钟
- [ ] 告诉至少 1 位信任的朋友/家人
- [ ] 如果涉及金钱，去银行说明情况、去派出所报案
- [ ] 卸载那个交友 App（暂时）

### 第 2-4 周: 整理
- [ ] 整理聊天记录和转账记录（为报案用）
- [ ] 写一封信（不需要发出去）表达你的愤怒和感受
- [ ] 恢复社交：每周至少和 1 位朋友见面
- [ ] 如果你在工作/学习，尽量保持正常节奏

### 第 1-3 月: 重建
- [ ] 反思：不是自责，而是成长
- [ ] 学习防骗知识（你已经在做了）
- [ ] 重新定义你想要的关系
- [ ] 当你准备好时，可以慢慢回到社交和交友中

## 需要寻求专业帮助的信号

如果以下情况持续超过 2 周，建议寻求心理咨询：

1. 持续的失眠或过度睡眠
2. 食欲显著改变（完全不想吃或一直暴食）
3. 对所有事失去兴趣（不想出门、不想见人、不想做任何事）
4. 反复出现被骗的回忆，无法集中注意力做其他事
5. 持续的自我否定和自责
6. 酗酒或其他物质依赖
7. **任何自伤或自杀的念头 — 立即求助，不要等**

## 给亲友的建议（如果你在支持一位受害者）

1. **不要责备**: 不要问"你怎么会被骗""为什么不早点发现"。这些话非常伤人。
2. **倾听**: 让对方说，你听着就好。不需要给建议，倾听就是最大的支持。
3. **陪伴**: 陪对方去报警、去银行。实际的陪伴胜过一万句"有事找我"。
4. **保持正常**: 不要一直聊被骗的事。也聊别的——日常、电影、八卦。让对方感受到生活还在继续。
5. **观察危险信号**: 如果对方持续情绪低落 >2周、提到自伤、完全不社交——建议对方寻求专业帮助。

## 重要认知

> 你被骗是因为你有一颗愿意相信别人的心。
> 这份信任被利用，是骗子的卑劣，不是你的耻辱。
> 保护好这颗心，但不要关上。
> 这个世界上值得信任的人和需要警惕的人都是存在的。
> 你能从这次经历中学到的，会帮助你和更多人。
