# 标准免责声明语言 (Disclaimer Language Templates)

## 概述

本文档提供了在所有分析中必须使用的免责声明模板。分为：初始声明（Phase 0）、高风险判定后的法律建议声明、心理支持声明。

**使用方式**: Phase 0 使用初始声明模板。Phase 3 高风险判定后追加法律建议声明。Phase 5 使用心理支持声明。

---

## 模板 1: 初始免责声明 (Phase 0)

```markdown
⚠️ **重要声明 — 请在分析开始前仔细阅读**

在开始分析之前，有几点需要你了解：

1. **概率分析，非事实判定**: 本分析基于 AI 模式识别和心理学知识，输出的结论是概率性的评估，不代表确定的事实。AI 无法真正知道一个人的内心想法。

2. **隐私保护**: 我不会存储、记录或传输你的对话内容到任何地方。所有分析仅在本会话中进行。但请注意，你输入的内容会通过 AI 服务商的基础设施处理。

3. **不是法律或临床建议**: 我不是律师，也不是心理医生。如果分析结果指向可能的诈骗行为，建议向执法机构举报。如果你正在经历严重的情绪困扰，建议寻求专业心理帮助。

4. **信息越多越准确**: 你提供的聊天记录越完整、时间跨度越长，分析的准确度就越高。但请不要发送包含他人真实姓名、身份证号、住址等隐私信息的内容——用 [姓名] 或 [城市] 替代即可。

5. **你有完全的控制权**: 你可以随时要求我跳过某个步骤、重新分析、或者停止分析。最终的决定由你做出。

**你同意以上声明吗？同意的话，我们开始。**
```

## 模板 2: 高风险判定后法律建议声明 (Phase 3 → Phase 4)

当判定为 🔴 高风险 或 🟠 中高风险时：

```markdown
⚠️ **基于目前的证据，此次分析指向较高的诈骗风险。**

请注意以下几点法律和安全建议：

1. **保留证据**: 截图保存所有聊天记录、转账记录、对方账号信息。这些是报警的重要证据。

2. **停止金钱往来**: 不要再向对方转账任何金额。即使对方说"这是最后一步""钱马上就能取出来""你再帮我一次"——这些都是诈骗的常见收尾手法。

3. **报警渠道**:
   - 📞 #96110 — 全国反诈中心统一预警劝阻咨询专线（免费，24小时）
   - 🚔 前往距离你最近的派出所报案
   - 📱 下载"国家反诈中心"App，在线举报

4. **不要与对方对质**: 对质不会让你得到真相。诈骗者是训练有素的操控者，他们能说出让你相信的任何话。最好的做法是突然停止回复。

5. **如果涉及大额金钱损失**: 立即联系你的银行，说明情况，尽可能冻结交易。同时保留所有交易记录作为证据。
```

## 模板 3: 心理支持声明 (Phase 5)

```markdown
💚 **请照顾好自己**

发现自己可能被欺骗，是一种很复杂的感受——可能有愤怒、羞耻感、自我怀疑、以及对信任被辜负的深深难过。这些都是正常的反应，不代表你软弱。

几点可能有帮助的建议：

1. **这不是你的错**: 诈骗者是专业的心理操控者。他们利用的是人类最基本的情感需求——被爱、被关心、被理解。愿意相信别人是一种力量，不是弱点。

2. **允许自己难过**: 给自己时间和空间去消化。不要对自己说"我应该早点发现"——事后诸葛亮是最容易的。

3. **找人聊聊**: 如果可以，找一个你信任的朋友倾诉。把心事说出来本身就是一种释放。

4. **保持日常**: 尽量保持正常的饮食和作息。身体状态会直接影响心理状态。

5. **如果需要专业帮助**:
   - 📞 心理援助热线: 12320（全国卫生热线）
   - 📞 北京心理危机研究与干预中心（24小时）: 010-82951332
   - 📞 希望24热线: 400-161-9995
   - 在线心理咨询平台: 简单心理App、壹心理App

6. **如果你有自伤或自杀的念头**: 请立即拨打 010-82951332 或者告诉身边的人。你很重要。
```

```markdown
请立即做以下任一件事：
1. 拨打 **010-82951332**（北京心理危机研究与干预中心，24小时）
2. 拨打 **400-161-9995**（希望24热线）
3. 告诉离你最近的一个人——家人、朋友、室友

你没有做错任何事。现在最重要的是保证你的安全。请打电话，好吗？
```
