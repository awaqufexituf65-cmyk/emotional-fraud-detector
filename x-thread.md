# Emotional Fraud Detector — X/Twitter Thread

## EN Version

1/ 🔍 I built an open-source emotional fraud detector for Claude Code.

It analyzes chat messages to detect romance scams—pig-butchering, sextortion, fake military personas. Not paranoia. Pattern recognition backed by real fraud data.

2/ Romance scams cost victims $1.3B+ annually (FTC 2024). In China, "pig-butchering" (杀猪盘) alone causes billions in losses each year.

Most victims don't report it—too ashamed. That's why I built this.

3/ What it does:

1. User profiling + WeFlow WeChat export
2. Per-message 7-dimension analysis (literal meaning / intent / manipulation / red flags / emotional strategy / relationship stage / how to respond)
3. 4-level risk verdict with confidence scores
4. Concrete safety guidance by risk level
5. Auto-triggered psychological support for high-risk findings

4/ Privacy-first:
- No data storage
- No network calls
- `allowed-tools: Read, AskUserQuestion, TodoRead, TodoWrite`
- All analysis in-session only

5/ Knowledge base detects 7 scam types:
- Pig-butchering (杀猪盘)
- Fake military/doctor
- Sextortion
- Investment mentor scams
- International parcel scams
- Emergency scams
- Intermittent reinforcement scams

8 manipulation tactics: Love bombing, future faking, isolation, guilt tripping, gaslighting, urgency creation, trauma bonding, intermittent reinforcement.

6/ Open source, MIT license. Cross-platform.

GitHub: https://github.com/awaqufexituf65-cmyk/emotional-fraud-detector

Sister project (self-analysis):
https://github.com/awaqufexituf65-cmyk/love-director

7/ If you're being scammed right now:
- Stop all money transfers immediately
- Save all chat records and transaction evidence
- Call #96110 (China Anti-Fraud Center)
- Don't confront the scammer—just stop responding

You deserve protection.

## 中文版

🔍 我做了一个开源的情感反诈分析 Skill：emotional-fraud-detector

它分析聊天记录，识别杀猪盘、网恋诈骗、情感操控。

不是制造焦虑——是基于模式识别的概率分析。

5阶段工作流:
1. 采集你的画像 + 对方信息
2. 引导用 WeFlow 导出微信聊天记录
3. ★ 逐条消息7维深度分析（字面意思/真正意图/操控手法/红旗等级/情绪策略/关系阶段/该怎么回）
4. 四级判定（高风险/中高风险/中度疑虑/低风险）
5. 分级应对指导 + 心理支持

知识库涵盖7种诈骗类型 + 8种心理操控手法。

隐私优先: 不存数据、不联网、不上传。
