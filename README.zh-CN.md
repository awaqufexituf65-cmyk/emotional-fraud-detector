# 情感反诈分析 (Emotional Fraud Detector)

一个为 Claude Code 打造的情感诈骗分析 Skill。

帮你在网恋中识别杀猪盘、网恋诈骗、情感操控——同时在你需要的时候，给你温暖的陪伴和专业的支持。

---

## 它能做什么？

✅ 分析聊天记录，识别情感诈骗模式（杀猪盘、冒充军人/医生、裸聊敲诈等 7 种）  
✅ 检测心理操控手法（爱情轰炸、煤气灯效应、情感绑架等 8 种）  
✅ 四级风险判定（高风险/中高风险/中度疑虑/低风险）  
✅ 给出具体可行的应对建议（报警、验证身份、安全脱身等）  
✅ 提供心理支持和求助资源（热线电话、心理咨询平台）  
✅ 采集使用者画像，提供个性化指导  

---

## 安装

```bash
# 克隆到 Claude Code skills 目录
git clone https://github.com/awaqufexituf65-cmyk/emotional-fraud-detector.git \
  ~/.claude/skills/emotional-fraud-detector
```

---

## 使用

在 Claude Code 中说：

> "帮我分析一下这个人的聊天记录，我怀疑可能有问题"

或者直接粘贴聊天记录，Skill 会自动触发。

---

## ⚠️ 重要

**这是一个辅助分析工具，不是真相判定器。** AI 给出的分析是概率性的，不是事实。如果确认遇到诈骗，请打 #96110 报警。如果情绪很难受，请打 12320 心理援助热线。
